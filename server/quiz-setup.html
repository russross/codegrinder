Steps to finish the testing center quiz setup

  1. Open a new tab or window to set up the quiz so you can keep these instructions open.
  2. Create and configure a Classic Quiz in this Canvas course. This quiz gives students access to CodeGrinder; their CodeGrinder grade is reported through the original assignment. Use an ungraded quiz type, such as Practice Quiz, to avoid a second gradebook entry.

    Leave the quiz’s access code unset here. LockDown Browser settings will fill it in automatically.

  3. Add one question and choose Text (no question) as its type. In the message, create a link that opens in a new tab:
